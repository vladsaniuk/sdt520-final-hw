## Notes

- **GRAPH-01/02/03 Descoped**: During development the system's core value was clarified: recommendations must be grounded in user-uploaded documents only. Hardcoded AWS knowledge injected into the LLM prompt would bias results. seed.py and the `/api/v1/seed` endpoint still exist for manual use but the advisor does not query seeded graph nodes. These requirements move to v2 backlog as "optional enhancement: pre-seed with Well-Architected whitepaper content that users can augment."
