# Phase 02.1: UI Polish & Visual Design — Context

> Decisions captured for gsd-phase-researcher and gsd-planner.
> Do not re-ask any decision listed here.

**Phase Goal:** Make the existing UI look professional and polished — AWS-branded layout,
styled sub-components (MermaidViewer, CodeSnippet, CostTable), welcome screen, and Geist
font. Mocks for unimplemented Phase 3 (conversation history) and Phase 5 (Terraform download)
are already in place.

**Requirements:** UI-01 (visual polish), BUG-04 (boolean fix), BUG-05 (mermaid.run)
**Note:** Core UI structure (sidebar, chat bubbles, demo data, KnowledgeBase page) was
implemented inline before this plan was created. Plans should document what was built and
close remaining gaps identified in this context.

---

## Decisions

### Responsive Design
- **Decision:** Desktop-only fixed sidebar — no mobile/responsive breakpoints
- **Rationale:** Demo tool; mobile layout is not a priority for v1

### Sub-Component Styling
- **Decision:** Full restyle to match AWS Console aesthetics
  - **MermaidViewer:** Dark header bar with "Architecture Diagram" label, white diagram area
  - **CodeSnippet (Snippet.tsx):** Token-colored syntax highlighting, dark code background, copy button
  - **CostTable:** Striped rows (alternating light/dark), bold totals row, service icon/badge column
- **Style reference:** AWS Console color palette — dark headers, orange accents, clean table rows

### Empty & Welcome State
- **Decision:** Friendly welcome screen when no messages exist
  - Centered layout with AWS Architecture Advisor logo/title
  - 3–4 prompt suggestion chips the user can click to auto-fill the input
  - Example prompts: "Serverless e-commerce API", "Multi-region DR setup", "ML inference pipeline", "Event-driven microservices"
  - Demo data (`DEMO_MESSAGES`) should be removed from default state — user starts with the welcome screen
  - Welcome screen disappears as soon as the first message is sent (or a suggestion chip is clicked)

### Typography — Font
- **Decision:** Geist font (Vercel)
  - Source: `@fontsource/geist` npm package OR Google Fonts CDN if package not available
  - Apply to `body` globally via `index.css` or `main.tsx`
  - Geist Mono for code blocks (`CodeSnippet`)

### Error States
- **Decision:** Agent's discretion — add a simple inline error banner ("Something went wrong — please try again") in ChatBox on fetch failure. No modal.
