## Design System

| Property | Value |
|----------|-------|
| Tool | none — raw Tailwind CSS classes |
| Preset | not applicable |

## Spacing Scale

Declared values (multiples of 4px, mapped to Tailwind defaults):

| Token | Value | Tailwind Class | Usage |
|-------|-------|----------------|-------|
| xs | 4px | `p-1`, `gap-1` | Icon gaps, inline padding |
| sm | 8px | `p-2`, `gap-2` | Compact element spacing |
| sm-dense | 12px | `py-3`, `gap-3`, `mb-3` | Tight vertical rhythm for dense tables and compact grouped elements |
| md | 16px | `p-4`, `gap-4` | Default element / card padding |
| lg | 24px | `p-6`, `gap-6` | Section padding |
| xl | 32px | `p-8`, `gap-8` | Layout gaps |
| 2xl | 48px | `py-12` | Major section breaks |
| 3xl | 64px | `py-16` | Welcome screen vertical centering |

**Exceptions:**
- Textarea `min-height: 44px` — touch/click target minimum (maps to `min-h-[44px]`)
- Send button `44px × 44px` — click target minimum (`h-11 w-11`)
- Prompt chips `py-2 px-4` — intentionally shorter than md to keep them pill-shaped

## Typography

| Role | Size | Tailwind | Weight | Class | Line Height | Usage |
|------|------|----------|--------|-------|-------------|-------|
| Body | 14px | `text-sm` | 400 regular | `font-normal` | 1.5 (`leading-relaxed`) | Chat bubble text, panel content, form inputs |
| Label | 12px | `text-xs` | 700 bold | `font-bold` | 1.3 (`leading-tight`) | Panel headers (ALL CAPS + tracking-wide), sidebar section labels |
| Heading | 16px | `text-base` | 700 bold | `font-bold` | 1.2 (`leading-tight`) | Sidebar conversation titles, section headings |
| Display | 24px | `text-2xl` | 700 bold | `font-bold` | 1.2 (`leading-tight`) | Welcome screen "AWS Architecture Advisor" title only |

**Code font:** Geist Mono at 12px (`text-xs` / `fontSize: '0.75rem'`), weight 400, used exclusively inside `<CodeSnippet>` and any `font-mono` contexts.

**Font install:**
```bash
npm install @fontsource/geist @fontsource/geist-mono
```

**Font import** — add to `frontend/src/main.tsx` before any other imports:
```ts
import '@fontsource/geist/400.css'
import '@fontsource/geist/700.css'
import '@fontsource/geist-mono/400.css'
```

**Global font** — add to `frontend/src/index.css`:
```css
@tailwind base;
@tailwind components;
@tailwind utilities;

body {
  font-family: 'Geist', system-ui, sans-serif;
}

code, pre, .font-mono {
  font-family: 'Geist Mono', 'Fira Code', monospace;
}
```

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` / `#F9FAFB` (white / gray-50) | Main content area bg, chat message area, card surfaces, assistant bubble bg |

| Destructive | `#EF4444` / `bg-red-50 border-red-200 text-red-700` | Inline error banner only |

**Accent (`aws-orange`) reserved for:**
1. Send button background (`bg-aws-orange`)
2. Active "Knowledge Base" nav item background
3. Sub-component panel header icons (SVG stroke color)
4. Textarea focus ring (`focus:ring-aws-orange/40 focus:border-aws-orange`)
5. KnowledgeBase progress bar fill
6. "Download .tf" button background
7. Assistant avatar circle background
8. Prompt chip hover state border/text highlight

**Never use accent on:** body text, sidebar backgrounds, table rows, or any decorative fills.

### Inline Error Banner (ChatBox)

**Trigger:** `catch` block in `handleSend` when fetch fails.
**Placement:** Replaces the current error message-bubble approach — rendered ABOVE the input bar, inside the scroll area as a non-bubble element.

```
┌─────────────────────────────────────────────────────────────┐
│ ⚠  Something went wrong — please try again.          [✕]   │
└─────────────────────────────────────────────────────────────┘
```

- **Container:** `mx-4 mb-3 flex items-center gap-2 px-4 py-3 rounded-lg bg-red-50 border border-red-200 text-red-700 text-sm`
- **Icon:** warning triangle SVG, `w-4 h-4 shrink-0`
- **Text:** `"Something went wrong — please try again."` — flex-1
- **Dismiss button:** `ml-auto text-red-400 hover:text-red-600` — × character, clears the error state
- **State:** Add `const [error, setError] = useState<string | null>(null)` in ChatBox
- **On send:** clear error at start of `handleSend`, set on catch
- **Do NOT** push error message into the `messages` array — it is a separate UI layer

## Responsive Scope

**Desktop only.** No mobile or tablet breakpoints. Minimum supported viewport: 1280px wide.

- Fixed sidebar width: `w-64` (256px) — no collapse, no drawer
- Main content: `flex-1 min-w-0` — fills remaining width
- Welcome screen chips: `flex-wrap` — wrap at narrow viewports but not a design requirement

## Font Integration

**Package-based (preferred over CDN):**

```bash
cd frontend && npm install @fontsource/geist @fontsource/geist-mono
```

**Import in `frontend/src/main.tsx`** (before React imports):
```ts
import '@fontsource/geist/400.css'
import '@fontsource/geist/700.css'
import '@fontsource/geist-mono/400.css'
```

**Global CSS in `frontend/src/index.css`:**
```css
@tailwind base;
@tailwind components;
@tailwind utilities;

body {
  font-family: 'Geist', system-ui, -apple-system, sans-serif;
}

code, pre, .font-mono {
  font-family: 'Geist Mono', 'Fira Code', 'Courier New', monospace;
}
```

**Fallback chain:** `Geist → system-ui → -apple-system → sans-serif`
