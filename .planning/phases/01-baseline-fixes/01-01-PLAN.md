**1. Rewrite backend/src/main.py (BUG-02 + BUG-06)**

The entire file must become:
```python
import os
from contextlib import asynccontextmanager
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from src.api.routes import router as chat_router
from src.api.knowledge import router as knowledge_router
from src.services.knowledge_base import KnowledgeBaseService


@asynccontextmanager
async def lifespan(app: FastAPI):
    """Startup: initialize Neo4j schema. Shutdown: close driver."""
    kb_service = KnowledgeBaseService()
    try:
        kb_service.initialize_schema()
    except Exception as e:
        print(f"[Main] Error initializing KB schema: {e}")
    yield
    kb_service.close()


app = FastAPI(title="AWS Architecture Advisor API", lifespan=lifespan)

# Configure CORS — read from env var; defaults to "*" for demo use
_raw_origins = os.getenv("ALLOWED_ORIGINS", "*")
allowed_origins = [o.strip() for o in _raw_origins.split(",")]

app.add_middleware(
    CORSMiddleware,
    allow_origins=allowed_origins,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/health")
def health_check():
    return {"status": "ok"}


# Include routers
app.include_router(chat_router, prefix="/api/v1", tags=["chat"])
app.include_router(knowledge_router, prefix="/api/v1/knowledge", tags=["knowledge"])


if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

Key changes versus current:
- `from contextlib import asynccontextmanager` added
- `@asynccontextmanager async def lifespan(app: FastAPI)` replaces `@app.on_event("startup")`
- `KnowledgeBaseService()` instantiated INSIDE lifespan (not at module level)
- `kb_service.close()` called on shutdown (after yield)
- `app = FastAPI(..., lifespan=lifespan)` wires the context manager
- `allow_origins=["*"]` replaced with env-var-driven `allowed_origins` list
- Module-level `kb_service = KnowledgeBaseService()` line REMOVED
