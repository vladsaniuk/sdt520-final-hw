Find the existing `lifespan` function:

```python
    """Startup: initialize SQLite DB + Neo4j schema. Shutdown: close driver."""
```

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    """Startup: initialize SQLite DB, Neo4j schema, and seed graph. Shutdown: close driver."""
    init_db()
    kb_service = KnowledgeBaseService()
    try:
        kb_service.initialize_schema()
        seed_graph()
    except Exception as e:
        print(f"[Main] Error on startup: {e}")
    yield
    kb_service.close()
```

**Why this is safe:** `seed_graph()` uses MERGE-based Cypher — calling it multiple times (container restarts) is idempotent and will NOT duplicate data.

Docker Compose volume mounts require these directories to exist on the host, otherwise Docker creates them as root-owned directories which can cause permission errors. Fix: commit empty `.gitkeep` stub files inside each required subdirectory, then add gitignore negation rules to allow them.

- `data/neo4j/logs/.gitkeep`

- `data/neo4j/plugins/.gitkeep`
